## 0. 结论

功能面已全；下一阶段收益在：

1. **正确性/安全**：默认就害人的缓存与错误泄漏  
2. **热路径性能**：模块读盘、HMR stampede、压缩、静态资源  
3. **可读性**：`csr-client-builder` / `App` 巨石增量拆分  

旧 7 月优化文部分过时（view/Node/AppKind 已进展）；以本文 + 升级总控为准。

## 2. 性能（摘要）

**Critical（已修或已降风险）**

- SSR load 跨用户缓存 → **默认关**  
- 未哈希 `_client.js` + immutable 一年 → **改为 must-revalidate**

**High（P1 热路径已修；其余仍开）**

- `loadRouteModule` 每请求读盘扫 CSS → **mtime 短路** ✅  
- HMR 双扫路由 + 无 in-flight 合并 → **单扫 + coalesced rebuild** ✅  
- 压缩默认关 → **非 dev 默认开** ✅  
- `/__data` 无 `Cache-Control: no-store` → ✅  
- 生产静态 JS / asset-manifest 每请求读盘 → **mtime/内存缓存** ✅  
- `dweb-cli run` 全量 App 冷启动 → **`console.slim` / `DWEB_CONSOLE_SLIM` opt-in** ✅  

**P2（另波已收）**

- Streaming SSR（view + `renderSSRStream`）✅；`/metrics` opt-in ✅；L1.5-b 产品报告 ✅  

## 3. 安全（摘要）

**High（部分已修）**

- `_error` / 默认 500 JSON 泄漏 → **P0 已修**  
- `cors: true` ⇒ `*`、Socket.IO 反射 Origin → **P1 已收紧**（警告 + socket-io 不反射 + 桥接）  

**Medium**

- console `..` → **P0 已修**  
- api init 缺安全配方、session `secure: false` 示例、rateLimit 信 XFF  

安全能力仍以 **opt-in** 为主（压缩除外：生产默认开）；init/PRODUCTION 要教人打开 CORS，而不是静默强制。
